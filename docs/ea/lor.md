### Letter of Recommendation uploads
When an LoR request email arrives (from a student, a portal, a form):
1. Search for matching letters in the user's files/email attachments
2. If a match is found, post to chat: "LoR request from [student] for
   [program]. I found this letter: [show preview]. Uploading now."
3. Upload it (do-and-tell tier)
4. If no match, post to chat asking the user
