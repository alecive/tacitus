# Plugin architecture

This guide moved to [docs/plugins.md](plugins.md). It covers both
manifest versions (v1, where a plugin's own `plugin.json` decides, and v2,
where the owner's lock decides), the two trust zones, `ea-plugin.py`
(install, consent, integrity, update), confirmation cards, owner verbs,
mail rules, `run-plugin.sh` and the shared ledger.
